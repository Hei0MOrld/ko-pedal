> 当日の細かい手順(コマンド付き)は **DAY1_SETUP.md**。OS は Bookworm の Lite(PiPedal の公式対応が Bookworm だけのため、10/3 に Trixie から変更)

## 2. ボタンが付く(SPEC ②、机の上で仮組み)

     UR12 を別電源にしても、LINE OUT を抜いても -50〜-53 のまま。**同じギター・ケーブル・UR12 をバッテリー駆動の Mac につなぐと -82 以下**(ハムも櫛もなし)→ ギター・UR12・部屋ではなく、ラズパイと公式電源の GND の揺れがギターの高いインピーダンスから入る(プロ 3 人の 1 位の説)。BYPASS が静かなのはギターの GND がアンプ側になるため。
     ※「ピックアップがラズパイの放射を拾う」は外れ。UR12 の POWER SOURCE は「USB 2.0」側に戻した。
     次: ラズパイの電源を替えて測る(モバイルバッテリー / 12V + Waveshare 降圧)→ アースに落とす / USB アイソレーター(UR12 は high-speed、安いのは full-speed のみ)を検討。
     **訂正(同日 KO の指摘どおり配線だった)**: アースなし・バッテリー駆動のまま、ギターを UR12 に直挿し(HI-Z のケーブルを抜く)= -86 dBFS(弾いて -18 平均、差 70 dB)/ ペダルの IN 経由 = -48.9。
     IN ジャックのスリーブと HI-Z ケーブルの網線が、Pico・LED・39 番と同じ GND の列に挿さっていた → ラズパイ → USB → UR12 → HI-Z 網線 → GND の列 → Pico → USB → ラズパイ の輪にラズパイの揺れが流れ、ギターの音に混ざる。
     **IN のスリーブ + HI-Z の網線だけを別の列にしたら -70.1**(21 dB 改善)。OUT 側も音の列に入れると悪化(-59〜-63)。OUT のスリーブ + LINE OUT の網線は GND の列のままがよさそう。ただし同じ配線のつもりでも -57〜-70 でばらつく(ブレッドボードの接触?スピーカーの有無?)→ 完成版はユニバーサル基板で「入口の GND は HI-Z の網線 1 点だけ」にする。
     バッファー 32〜512・エフェクト全部 OFF でもノイズの量は同じ(色だけ変わる)。抵抗プラグ 100k は -78。TQ2-5V の 5・6 番は GND ではない(未使用)。
     試遊用プリセット「試遊 クリーン」(29、Edge of Breakup NAM、1 コーラス / 2 ディレイ / 3 リバーブ、ゲートは先頭)を作って保存済み。前のバンクは Pi の /home/ko/Default+Bank.bank.before-shiyuu
   - **10/21 夜 E-3 v1.2 保存**: HOME でつまみ 2 秒長押し → 「上書き保存する?」(押す = 保存 / 左右 = やめる / 8 秒で戻る)→ PiPedal の saveCurrentPreset → onPresetChanged(false)で pi/pedal-persist(sudo)が /var/pipedal/presets の変わったファイルだけ SD 本体(/media/root-ro を数秒だけ rw)へ。1 つ前は /var/pipedal/presets-bak/。保護 ON のまま入れた(同じやり方で lower にも置いた)。実機の保存はまだ試していない
   - **11/1 手順 F 決定(KO「お勧めでOK」)**: 電源は**公式 5A の USB-C だけ**(手順 A の 12V・降圧・入口の保護はやめる)。UR12 と Pico はラズパイの USB から(UR12 の POWER SOURCE = USB)。音の部分(TQ2・2SC1815・1kΩ・1N4148・ジャック/ケーブルの着地)をユニバーサル基板へ、入口の GND(IN スリーブ+HI-Z 網線)は島にして他とつながない。手順ページ docs/step_f_board.html(step_f_board.html、配置図は tools/board_svg.py)。DI は大学のミキサーで確かめてから同じ基板の右側へ
4. ~~**電源回路**: 12V → 5V。~~(11/1 やめた。上の手順 F)Pi 用と、UR12・LED・Pico 用で系統を分ける。12V 入口の保護(逆接続・過電流)
