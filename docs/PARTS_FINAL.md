## プロのチェックで変わったこと

- **足した**: 12V 入口の保護(ヒューズ・逆接続・TVS。9V センターマイナスの挿し間違いが現場で一番多い)/ 出口のバッファ / PhotoMOS(ボツッ対策、TUNER で DI も無音)/ 積み重ね用ヘッダー / USB-C ピグテール / アクリル窓 / SD の控え
- **削った**: スーパーキャパの UPS(Pi 5 の 5A を支えるには大がかり)→ overlay で読み取り専用 + 音色の保存先だけ別の区画
- **変えた**: 音用の電源は小さい降圧 → 9V LDO / 降圧は 8A 1個 → 5A(Pi)+ 3A(ほか)の2系統 / 箱は木だけ → アルミ天板 + 内側テープ

## 方式の決定(推奨どおり仮決め)

| 項目 | 決め | 理由 |
|---|---|---|
| DI | トランス | 絶縁されて GND LIFT が効く。ファンタム 48V も通さない |
| リレー | 非ラッチ | 電気が来ないと素通り、が仕様どおり |
| 音の基板 | HiFiBerry DAC+ADC Pro | Pi 5 対応・PiPedal の実績。Pisound は1万円高い |
| 液晶 | Pico につなぐ | Pi が起動中・停止中でも「BOOT」「BYPASS」を出せる。音色の名前は Pi から SysEx |
| Pi の生存確認 | GPIO の線1本、音の処理(JACK)の中から出す | OS が生きて音だけ止まる故障も拾える |

## 忘れやすい設定・注意

- Pi 5 の EEPROM に `PSU_MAX_CURRENT=5000` を書く。書かないと USB が 600mA に絞られ、Pico や増設箱が不安定になる
- Pico は Pi の USB と 5V(LED 用)の両方から給電。Pi が再起動しても Pico は落ちず、リレーを守り続ける
- HAT とクーラーが当たらないかは推測。届いたら実物で確かめる
