# A. 電源(2026-10-18、中身を完成させる 6 段階の 1 つ目)

KO「箱と増設箱以外の中身は完成させたい」→ A 電源 → B リレーで音を通す → C 足元 → D DI → E 画面とつまみ → F ユニバーサル基板にまとめる。
A は「12V のアダプター 1 本から、ラズパイ用とそれ以外用の 5V を 2 系統作る」。ほかの全部がここから電気をもらうので最初にやる。

## 部品(全部手元にある)

| 部品 | 役目 | 向き |
|---|---|---|
| FSP036-DHUA1(12V 3A、5.5/2.1mm、センタープラス) | 元の電源 | — |
| DC ジャック A-2237 | 入口 | 真ん中のピンが +。差してテスターで確かめる |
| ポリスイッチ MF-R300 | 流れすぎたら切れる(冷えると戻る) | 向きなし |
| ショットキー SB340LS | 逆に挿した時に電気を通さない | **帯(カソード)を出口(12V の線)の側に** |
| TVS P4KE15A | 電圧の跳ね上がりを逃がす | **帯を +12V の線に、反対を GND に**(線と GND の間に橋渡し) |
| コンデンサ 100µF 25V くらい(手持ち) | 12V の線を落ち着かせる | + を 12V に(長い足 = +) |
| 降圧基板 Waveshare 29035 × 2 | 12V → 5V(4A)。入力 6〜36V、最初から 5V 出力 | 左 = 入力 VIN+ / VIN−、右 = 出力 VOUT(+) / GND(−)。端子なし(線をはんだ付け) |
| コンデンサ 1000µF 16V(秋月) | LED リングを、電源を入れた瞬間の電流から守る | + を 5V に |

## 配線

```
アダプター 12V ─ DC ジャック(真ん中 +)
   + ─ ポリスイッチ ─ ショットキー(帯→)─┬─ 12V の線 ─┬─ 降圧①  VIN+ ─→ 5V ① ラズパイ
   │                                   │             └─ 降圧②  VIN+ ─→ 5V ② UR12 / LED リング
   │                               TVS(帯が上) + 100µF
   − ─────────────────────────────────┴─ GND の線(①② の VIN− も GND も全部ここ)
```

- **5V ① → ラズパイ**: GPIO の **2 番と 4 番(5V)** に +、**6 番と 14 番(GND)** に −。太めの線で短く(2 本ずつに分けて流す)
  - **ラズパイの USB-C には何も挿さない**(GPIO と USB-C の両方から 5V が来るとぶつかる)
  - ラズパイ側の設定(つなぐ前に、いつもの USB-C 電源で起動して Claude が ssh で入れる):
    EEPROM に `PSU_MAX_CURRENT=5000`、`/boot/firmware/config.txt` に `usb_max_current_enable=1`。
    GPIO から電気を入れると、ラズパイは電源の力が分からず「電源不足」の警告を出したり USB を 0.6A に絞ったりするため
- **5V ② → UR12**: 切って使う USB A-microB の赤 = +、黒 = −。UR12 背面の POWER SOURCE を **5V DC**(micro-USB 側)に
- **5V ② → LED リング**: 5V と GND。リングの近くに 1000µF(+ を 5V に)
- **Pico は今まで通りラズパイの USB から**(MIDI と電源を 1 本で)。GND は USB でつながるので共通になる

## 確かめる順番(何もつながずに測ってから、1 つずつつなぐ)

1. アダプターを DC ジャックに差して、**真ん中のピンが +12V** か測る(ジャックの足のどれが真ん中か)
2. ポリスイッチ・ショットキー・TVS・100µF をつないで、12V の線を測る → **11.5〜11.8V くらい**(ショットキーで 0.3〜0.5V 下がる)
3. 降圧①②の入力をつないで、**それぞれの出力が 5.0〜5.2V** か測る。**3.3V だったら止める**(3.3V 用に設定されている)
4. 5V ② に UR12 だけつなぐ → 電源ランプがつく
5. ラズパイの設定(上)を済ませてから、5V ① に GPIO でつなぐ → 起動して、PiPedal で音が出る
6. 弾きながら `vcgencmd get_throttled` が **0x0**(電圧不足が一度も起きていない)、`vcgencmd pmic_read_adc EXT5V_V` が 5V 近く
