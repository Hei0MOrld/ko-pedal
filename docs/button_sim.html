BASS PEDAL / 操作のイメージ 2026-10-03

押して試す 琥ペダル

スイッチ1つが、エフェクター1台。本体に3台、増設箱を足すたびに3台ずつ増えます。どのスイッチにどのエフェクターを割り当てるかは自由です。本体の 1 / 2 / 3 は長押し(0.6秒)すると、覚えておいた ON / OFF の組み合わせに切り替わります(最初は3つとも空き)。両端の TUNER と BYPASS は役割が固定です。スイッチを押すと、LED と画面と音の流れが変わります。

琥KO BASS RIG
└ USB ─
増設箱 ID 02
青 = ON のエフェクト 琥珀の外枠 = 長押し中 消灯 = OFF / 割り当てなし 赤 = TUNER 白 = BYPASS

試してみる順番

  1. スイッチを短く押して、好きなエフェクトを ON / OFF する(例: SansAmp と B7K だけ ON)
  2. 下の「今の ON / OFF を長押し1に覚える」を押す
  3. ほかのスイッチをいろいろ押して音を変える → 画面に「*」が付く
  4. 本体の 1 を長押し → 覚えた組み合わせに一発で戻る。1 を短く押すと、1番のエフェクトだけ ON / OFF
  5. 何も覚えていない 2 / 3 を長押し → 「まだ覚えていない」と出るだけ
  6. TUNER / BYPASS → チューナー / リレーで直結(ラズパイが固まっても効く)

スイッチの中身はいつも同じなので、足で覚えられる。音の順番(コンプ → Noble → Butler → SansAmp → B7K → オクターバー)はスマホで決めて、スイッチの場所とは関係ない。本体の 1 / 2 / 3 だけは、長押しと見分けるため ON / OFF が足を離したときに切り替わる(0.6秒以上で長押し)。増設箱・TUNER・BYPASS は踏んだ瞬間に切り替わる。組み合わせの中身はスマホで覚えさせる。スイッチに入れたエフェクターは例(Noble / Butler / SansAmp / B7K は 10/3 に TONE3000 で使った音、コンプとオクターバーは仮)。割り当てはスマホで自由に変えられる。
