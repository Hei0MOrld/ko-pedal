ラズパイの向き(2 つの面の問題)

ラズパイ 5 は、USB-C・HDMI が長い辺、USB-A・LAN が短い辺にあって、2 つの面に分かれています。

  • 長い辺を背面(引き出しの前板)に向ける:電源の USB-C と HDMI がそのまま外から挿せる。延長線が要らない
  • USB-A は箱の中(右の UR12・Pico の方)を向く。中の 2 本だけなので、余りを 10cm くらい持たせれば引き出しを半分開けられる
  • GPIO は手前の辺になって、天板の画面に近い
  • ラズパイとして使うとき:前板から HDMI と電源を挿すだけ。全部抜くときは USB 2 本と画面の線を外す

リレーは Pico 基板の上

リレー(TQ2)とそれを動かすトランジスタは、Pico と同じユニバーサル基板に載っています。そこで 3D では Pico 基板を、ジャックに近い右の床に置きました。

  • 電気が来ていない・BYPASS のとき:IN → OUT を直接つなぐ(ラズパイが止まっても音が出る)
  • エフェクトのとき:IN → UR12 の HI-Z、UR12 の LINE OUT → OUT
  • 入口の GND(IN のスリーブと HI-Z の網線)は島にして、Pico の GND とつながない

右に寄せたので、TUNER の線は約 30cm になります(左端まで行くため)。
