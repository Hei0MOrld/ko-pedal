琥ペダル 完成図

中にラズパイ 5 が入ったベース用のペダルです。本体はフットスイッチ5つ（割り当てできる3つ + TUNER + BYPASS）と音量つまみ1つ。ボタンが足りなければ、増設箱をケーブルでつないでいくつでも足せます。音作りはスマホのブラウザで、AI と話しながらできます。

本体（上から見たところ）

大きさは目安。LED の色の例：青 = ON のエフェクター（2・3）、消灯 = OFF（1）。TUNER 中は赤、BYPASS 中は白。両端の TUNER と BYPASS は役割が固定
フットスイッチ
5つ。1 / 2 / 3 はスイッチ1つにエフェクター1台（何を割り当てるかはスマホで選ぶ）。短く押すと ON / OFF、長押しで覚えておいた組み合わせ（3つ）を呼び出す。TUNER は踏むと音が消えてチューナー。BYPASS はリレーで素通りにするので、ラズパイが固まっても効く
LED リング
役割で色が変わる。ライブでも足元で今の状態がわかる
画面
2.0〜2.4インチのカラー液晶。ON のエフェクターと、スイッチの並びどおりの名前を出す。足元から読める文字の大きさ
VOLUME
全体の音量。エフェクターごとの音量は中でそろえておく
見た目
「琥」のロゴ。レリック加工かオイル仕上げ
中身
Raspberry Pi 5（4GB）+ HiFiBerry DAC+ADC Pro + 自作 Hi-Z バッファ。ソフトは PiPedal。スイッチと LED は中の Pi Pico が受け持つ

背面（ジャックの並び）

  • 電源を入れてから起動するまでの間や、故障したときは、リレーで IN と OUT を直結して音を素通りさせる。起動は15秒以内が目標
  • DI OUT は PA 卓に直接送るため。ハムが出たら GND LIFT を切り替える
  • DI の PRE / POST で、PA に送る音を選ぶ。PRE = エフェクト前のきれいな音、POST = 作った音。アンプを持って行かないときは POST
  • DC ジャックはロック付きにして、本番中に抜けないようにする
  • EXP にエクスプレッションペダルをつなぐと、踏み込み具合でワウ・音量・オクターバーの混ぜる量などをなめらかに動かせる。何を動かすかはスマホで割り当てる。最大2台

増設箱

  • 箱ごとに ID をマイコンに書き込んである。並べ替えても、ボタンの割り当てはずれない
  • 本体が自動で見つけて、画面にも出す。スイッチ1つにエフェクター1台。箱を足すほどエフェクターが増える（何を割り当てるかはスマホで選ぶ）
  • ステージ用に頑丈にするなら、ケーブルを etherCON（頑丈な LAN）、通信を CAN にする案もある

つなぎ方
