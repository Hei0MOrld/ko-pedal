箱の中で固定する UR12 のつまみ・ボタン

  • GAIN（HI-Z）：一番強く弾いても割れない位置で固定
  • OUTPUT：LINE OUT とヘッドホンの音量が同時に決まる。BYPASS の ON/OFF で音量が変わらない位置で固定し、ふだんの音量は PiPedal の出力（画面のつまみ）で変える
  • DIRECT MONITOR：OFF（素の音が混ざらないように）。+48V：OFF

配線のルール

  1. 音の線は右側だけで完結させる。シールド線を使い、網線は片側だけ GND へ
  2. USB は 15〜30cm の短いもの。音の線と並べず、交差するなら直角に
  3. 降圧コンバーターは音の側から一番遠い左奥
  4. GND は 12V 保護の1点に、部品ごとに別の線で集める
  5. UR12 の2枚は裏面どうしを合わせ、間に絶縁シート＋GND につないだ薄い金属板
  6. 銅テープは箱の内側全体、その1点に1本だけつなぐ。Pi の上に通気口

決めること・測ること

  • UR12 の実測：端子が並ぶ2辺を定規を当てて真横から撮影、一番背の高い部品（コンボジャック・つまみ）の高さ
  • UR12 の平たいケーブル3本が、U 字に折り返せる長さか（電源を抜いて、ゆっくり）
  • L字の USB ケーブル（A-C は Pi の電源用ではなく、A-B／A-microB 系）を買い足す
  • 背面ジャックの胴体が、重ねた UR12（高さ約35mm）の上に収まるか
  • 画面は Pi の SPI につなぐ案でよいか（S1〜S3）
  • UR12 のヘッドホン出力を背面に出すか（A9）
