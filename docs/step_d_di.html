ペダルの DI 出力(手順 D)

PA のミキサーに送る XLR の出口を作ります。UR12 の LINE OUT L(エフェクトがかかった音)を、抵抗でマイクの大きさまで下げて XLR に出します。 部品はぜんぶ届いた部品セットと、注文済みの XLR(A-613)・トグル(A-4567)です。買い足しはありません。

しくみ

音を下げる(約 −30dB)10kΩ と 330Ω で、ライン(UR12 の出口)の大きさをマイクの大きさにする。ミキサーのマイク入力にそのまま挿せる
ノイズに強くするXLR の 3 番(COLD)にも、2 番と同じ 330Ω を GND までつなぐ。長いケーブルで乗るノイズを、ミキサーが打ち消せる
48V よけミキサーのファンタム電源(48V)が来ても通さない。50V のコンデンサー 1 個では余裕がないので、10µF 50V を 2 個まっすぐつないで 100V まで耐える
GND LIFTトグルで XLR の 1 番と GND を切り離す。ブーンというノイズが出たときに切り替える
BYPASS と TUNER のときは DI も無音BYPASS では音が UR12 を通らないので、DI には何も来ません。エフェクト前の音(PRE)が欲しくなったら、あとで足します。

回路図

10µF の向き: 長い足と、帯のない側が +。帯(−)の側を点 A・B(回路側)に、+ を XLR 側に。2 個つなぐときは、1 個目の + と 2 個目の − をつなぐ。

手順

  1. 電源を抜く(アダプターを抜いた状態で作業する)
  2. XLR に線を 3 本はんだ付け。端子の根元に小さく 1・2・3 と書いてあります。線の色を決めておく(例: 2 = 赤、3 = 白、1 = 黒)
  3. トグルに線を 2 本。真ん中の足と、端の足 1 本。もう片方の端は空けておく
  4. ブレッドボードの空いている所に、点 A と点 B の列を 1 つずつ決める
  5. リレー 7 番の列(UR12 LINE OUT L が来ている列)→ C1 10µF(+ がリレー側)→ 10kΩ → 点 A の列
  6. 点 A の列 → 330Ω → GND の列。点 B の列 → 330Ω → GND の列
  7. 点 A → 10µF(− が点 A)→ 10µF → XLR の 2 番。2 個のそれぞれの横に 1MΩ
  8. 点 B → 10µF(− が点 B)→ 10µF → XLR の 3 番。2 個のそれぞれの横に 1MΩ
  9. XLR の 1 番 → トグルの真ん中。トグルの端 → GND の列
ブレッドボードの GND の列長い列は真ん中で切れています。DI を右半分に作るなら、左右をジャンパー線でつなぐ。

トグルの「鳴る側」が GND つなぎ(ふだん)、「鳴らない側」が LIFT。箱に付けるときに文字を書きます。

大学のミキサーで音を確かめる

  1. そのチャンネルの フェーダーを下げ、GAIN を最小にする。+48V(ファンタム)が OFF か確かめる
  2. XLR ケーブルでペダルの DI とミキサーのマイク入力をつなぐ
  3. ペダルの電源を入れて、起動したら弾きながら GAIN を上げる(マイクと同じくらいの位置で足りるはず)。フェーダーを上げて音を出す
  4. 1・2・3 を踏んで、エフェクトの変化が PA から聞こえるか確かめる。BYPASS と TUNER では DI が無音になるのが正しい動き
  5. ブーンというノイズがあれば、LIFT を切り替えて減るか聞く
  6. 余裕があれば: フェーダーを下げてから +48V を ON にして、また音を出す。音もノイズも変わらなければ 48V よけが効いている。ON/OFF はフェーダーを下げているときだけ
すぐやめるとき大きなボツッという音が続く、音が割れる、どこかが熱い → フェーダーを下げて、ペダルの電源を抜く。結果を Claude に教えてください。
