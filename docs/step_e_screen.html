ペダルの画面配線(手順 E-1)

3.5 インチの画面(Tayda A-8182、ILI9488、480×320、裏の型番 MSP3520 系)をラズパイの SPI につなぎます。 つないだあと、SPI を有効にしてテストの絵を出すのは Claude がやります。

はじめに

ラズパイの電源を抜いてから線を挿す・抜く。5V(2 番)と 3.3V(17 番)の線の先が、ほかのピンに触れないように。5V が信号のピンに入るとラズパイが壊れます。

画面の基板には 3.3V を作る部品(U1)が載っているので、VCC は 5V で大丈夫。信号は 3.3V なのでラズパイと直結できます。タッチ(T_ の 5 本)と SD カード(SD_ の 4 本)は使いません。

画面のピン(裏から見た図)

裏の黄色いピンの列。上から T_IRQ … CS・GND・VCC の順(写真と同じ向き)。灰色はつながない。

ラズパイのピン

5V 3.3V GND SPI(絵のデータ) 画面の制御

ラズパイを上から見て、ピンの列を横向きに置いた図。USB・LAN の端子から遠い方の端が 1・2 番。 基板の内側の列が奇数(1, 3, 5…)、ふち側の列が偶数(2, 4, 6…)。

画面のピンラズパイ役目

確かめる順番

  1. 電源を入れる前に、テスターの導通で 2 番(5V)と 6 番(GND)の間が鳴らないことを確かめる
  2. 電源を入れる → 画面が白く光れば電源とバックライトは OK(まだ絵は出ません)
  3. Claude が SPI を有効にして、テストの絵(色の帯と文字)を出す
  4. 絵が出たら E-1 完了。次は E-2: つまみを回すとエフェクトの値が変わり、画面に出る
白いまま絵が出ないときCS・D/C・RESET・SDI・SCK の 5 本のどれかが違う列。とくに D/C(18 番)と RESET(22 番)の取り違えが多い。
画面が光らない・ラズパイが落ちるすぐ電源を抜く。VCC と GND が逆、または 5V がほかのピンに触れている。
