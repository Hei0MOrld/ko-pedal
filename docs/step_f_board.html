ペダルの音の基板(手順 F)

ブレッドボードの音の部分(リレー・ジャックの線・リレーを動かすトランジスタ)を、ユニバーサル基板に移します。 10/21 に一番静かだった(-70 dBFS)つなぎ方を、そのまま基板に写します。部品は全部いま使っているもので、買い足しはありません。

決めたこと:電源は公式 5A の USB-C だけ

やめるもの手順 A の 12V アダプター・降圧(Waveshare)・12V の入口の保護。10/18 にコンデンサーが破裂した部分が丸ごと要らなくなります。
電気の流れ公式 5A 電源 → ラズパイの USB-C。UR12 と Pico はラズパイの USB から(10/21 に測って EXT5V 5.06V・電圧低下の記録なし)。UR12 の POWER SOURCE は USB 側。

この基板には電解コンデンサーがありません。LED リングの 1000µF はリングの側のままで、この基板には来ません。

大事なきまり:GND は 2 つの島に分ける

入口の GND(島)IN ジャックのスリーブと、HI-Z ケーブルの網線の 2 本だけ。ほかの何ともつながない。UR12 の中で GND につながります。
制御の GND(列)Pico の GND、トランジスタの E、OUT ジャックのスリーブ、LINE OUT の網線。10/21 は OUT 側をこちらにしたほうが静かでした。

ブレッドボードでは、入口の GND が Pico・LED・ラズパイと同じ列にあったせいで、ラズパイ → UR12 → 網線 → 列 → Pico → ラズパイ の輪ができて -50 dBFS になっていました。分けたら -70 dBFS。

11/1 の切り分け:残りの「ジーー」は入口の配線が拾っているベースの音量 0・エフェクトを通す状態・UR12 のヘッドホンで、小さくジーー。ベースを UR12 の HI-Z に直接挿すと静か → 雑音は「入力ジャック → リレー → UR12 の HI-Z」の線で拾っていて、NAM の歪みが大きくしている。基板では次の 3 つを守る:
① 入力ジャック〜基板、基板〜UR12 の線をできるだけ短く ② 基板(L15/L17)〜UR12 の HI-Z はシールド線(ギターケーブルを短く切ったものでよい)、網線は入口の GND の島(L17/L18)だけに ③ その線をラズパイ・USB・LED リングの線から離して通す。
(BYPASS 中やケーブルを抜いたときのジーーは、UR12 の入力が浮くため。BYPASS の音は OUT ジャックの先で聞くもので、故障ではない。)

部品と線を 1 本ずつ

  1. リレー TQ2-5V を D11〜D15 / G11〜G15 に置いて、まず四隅の 4 本だけはんだ付け(向きの直しがきくように)。合っていたら残りも。5 番・6 番は何もつながない。
  2. ダイオード 1N4148 を D10〜G10 に縦に。帯を G 側(下、1 番の側)。D10–D11、G10–G11 をはんだでつなぐ。
  3. トランジスタ 2SC1815 を B6・B7・B8 に。平らな面を上(奥)に向けると、左から B・C・E になります(ブレッドボードのときと逆向き。足の名前で合わせてください)。
  4. 抵抗 1kΩ を B2〜B5 に横に。B5–B6(ベース)をはんだでつなぐ。
  5. 裏の線:B7(C)→ D11(リレー 10 番)。
  6. 制御の GND の列:すずめっき線を I1〜I19 に。裏で B8(E)→ I8。
  7. +5V:裏で D1 → G9、G9–G10 をはんだでつなぐ(リレー 1 番へ)。
  8. 素通りの線:裏で D12(9 番)→ G12(2 番)。電気が来ていないときに IN → OUT を直結する線です。
  9. 音の線の行き先:A13 → D13(8 番)、A15 → D14(7 番)、L13 → G13(3 番)、L15 → G14(4 番)。
  10. 入口の GND の島:L17–L18 をはんだでつなぐだけ。ほかとはつながない。

当てるところ正しい結果違ったら
L13 ↔ A13鳴る(素通りの道 3→2→9→8)D12–G12 の裏の線、リレーの向き
L13 ↔ L15鳴らない3 番と 4 番の間にはんだが流れていないか
A13 ↔ A15鳴らない8 番と 7 番の間
L18 ↔ I1鳴らない(島が分かれている)入口の GND がどこかに触れている
D1 ↔ I1鳴らない+5V と GND がつながっている。電気を入れない
B8 ↔ I1鳴るE → I8 の線

つないで鳴らす

  1. 表のとおりにジャック・ケーブル・Pico の線をはんだ付け。ブレッドボードの音の部分(リレー・トランジスタ)は外す。
  2. 電源を入れる前に、ベース → IN、OUT → アンプで音が通るか(電気なし = 素通り)。
  3. 電源を入れて、BYPASS OFF でリレーがカチッ。エフェクトがかかる。BYPASS ON で素の音。
  4. 静かさを測る:ベースのボリューム 0 で python3 noise.py 10 <チェーンの番号>(10/21 と同じ道具)。
  5. 弾いている途中で電源を抜く → 音が素通りで続く。もう一度挿して普通に起動する。
うまくいったとき-70 dBFS 前後。ブレッドボードの -57〜-70 のばらつきがなくなっていれば成功。
電源を入れて変なとき(熱い・焦げくさい・ラズパイが落ちる)すぐ抜いて、熱い部品を指で探してから写真を送ってください。原因を探すのはそのあと。

Pico 基板から出す線の長さ(箱に入れたときのイメージ)

箱はまだ決まっていないので、10/14 の内部配置の案(幅 330 × 奥行き 120mm、奥 65 / 手前 45mm のくさび形、スイッチ 5 つを 65mm 間隔で横一列)で見積もりました。 Pico 基板は床の真ん中、スイッチ 2 の奥に置く案です。

決まり:長めに付けて、箱に入れるときに切りそろえる いまは Pico 基板の側だけをはんだ付けして、表の長さで切っておけば足ります。反対側は、ブレッドボードで試す間はそのまま挿して使えます。 スイッチは天板(フタ)に付くので、フタを開けて裏返せるだけの余り(約 5cm)を、長さに入れてあります。

線の端にマスキングテープで「1」「T」「B」などと書いておくと、箱に入れるときに迷いません。 Pico 基板の上では、スイッチの線は手前の辺、つまみの線は奥の辺、GP9 は右の辺から出すと、線が基板の上を横切りません。

手順の行を押すと「済み」になります(このブラウザに覚えます。もう一度押すと戻ります)。

DI(XLR)はこの基板に入れていません。大学のミキサーで鳴るのを確かめてから、同じ基板の空いているところ(右側)に移します。
